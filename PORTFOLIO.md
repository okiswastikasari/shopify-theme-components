# Shopify Swimwear Store Case Study

## Challenge

Create a flexible Shopify storefront for a DTC swimwear brand.

## Solution

Built custom Online Store 2.0 components:

- Product recommendation engine
- Bundle builder
- Sticky add to cart
- Dynamic product information

## Technologies

- Shopify Liquid
- JavaScript
- CSS
- Metafields
- Cart API

## Ecommerce Goals

- Increase product discovery
- Improve conversion experience
- Increase average order value
