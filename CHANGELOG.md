## [1.0.0] - Initial Release


### Added

- Custom Shopify Online Store 2.0 sections
- Product recommendation component
- Bundle builder component
- Sticky add to cart functionality
- Product information metafield section
- Reusable product card snippet
- Custom JavaScript and CSS assets
- Product JSON template
- Shopify theme configuration settings
- Setup documentation

#### Product Recommendations

- Dynamic collection recommendations
- Product tag based logic
- Responsive carousel


#### Bundle Builder

- Multi-product selection
- Cart API integration
- Custom bundle experience


#### Sticky Add To Cart

- Persistent add to cart action
- Variant selection
- Mobile optimized UX


#### Product Information Tabs

- Shopify metafield integration
- Dynamic product attributes
- Merchant editable content
